# 精準停車驗收標準

設計稿：https://claude.ai/artifact/RiQLtX1utjr2wC4BmJkL62（左側「討論整理與規格」第 1–18 題）

實作完成後，逐條比對這份清單。共 91 條，每條都有編號和檢查方式。

最近一次驗收：2026-11-16（結果欄）。

## 怎麼使用

1. 實作完成後，每一條都實際執行檢查，不憑印象判斷。
2. 每條記錄結果：通過、不符、無法驗證，並附上證據（測試名稱、截圖或指令輸出）。
3. 不符的項目整理成清單，寫明現況和規格差在哪裡，然後修正。
4. 修正後重跑受影響的條目，再跑一次品質關卡（Q 組），確認沒有改壞別的地方。
5. 最後交出一份驗收報告：通過幾條、修了哪些、還有哪些需要人工確認。

規格之後如果有變動，先改這份清單，再改程式。
