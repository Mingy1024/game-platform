# 累計遊玩次數：驗收標準

- 實作計畫：docs/plans/play-count.md
- 檢查方式：U 單元測試、E E2E、C 檢查程式或文件

| 編號 | 規則 | 檢查 | 結果 |
|---|---|---|---|
| C1 | 玩完一局（出現結算畫面）回報一次；結算畫面停著不會再送 | E | 通過（2026-11-28）｜E2E「玩完一局只回報一次遊玩次數」（礦坑大逃亡） |
| C2 | 同一個代碼只加一次，拿去別的遊戲也不加；並行請求不會少算 | U E | 通過（2026-11-28）｜單元「同一個代碼重送只加一次」「同時送出多個請求不會少算」、E2E「同一局的代碼只加一次」 |
| C3 | 回報失敗（離線、403、429、5xx）不重送 | U | 通過｜單元「每次只送一個請求、帶新的代碼，失敗不重送」 |
| C4 | 只接受站上的遊戲（其他回 404）；跨站回 403；runId 不是 16–64 個 [A-Za-z0-9_-] 回 400；都不會加 | U E | 通過（2026-11-28）｜單元檢查、E2E「不是站上的遊戲回 404…」 |
| C5 | 同一個 IP 每分鐘超過 10 次回 429 | E | 通過（2026-11-28）｜E2E「同一個 IP 每分鐘超過 10 次回 429」 |
| C6 | 次數未滿 100、讀取失敗都不顯示；達 100 顯示「已被玩 N 次」（千分位），文字不帶遊戲主題 | U E | 通過（2026-11-28）｜單元門檻、E2E site.spec L2 L3、各遊戲 L2 |
| C7 | 只存遊戲代號與總數；代碼表不存玩家、IP；代碼 2 天後由每日排程刪除，總數不變 | U C | 通過｜單元「計數表只存遊戲代號與總數…」「清掉 2 天前的代碼…」 |
| C8 | 開關 `FEATURE_PLAY_COUNT` 關閉時不回報、API 回 404、畫面不顯示；不需要登入（登入關閉也能用） | U C | 單元通過（關閉不送）｜`guarded(…, { playCount: true })` |
| C9 | 隱私頁在開關打開時說明收集的資料與保存期間 | C | 通過｜`app/pages/privacy.vue` |
| C10 | 七種語言都有 `playCount` 文字 | U | 通過｜`lib/i18n/__tests__/dictionaries.test.ts` |
